SecondScrn display test pattern

Open this file on the Windows tablet display. Set browser zoom to 100 %. For a one-device-pixel pattern, use Windows scaling at 100 % too. Compare native resolution with a scaled stream, with GSR on and off. This is a visual check, not a calibrated colour or latency measurement.

Colour bars

White · yellow · cyan · green · magenta · red · blue · black. Look for neutral white/grey and no obvious tint or washed-out blacks.

Near black and near white

Fine lines and text

Black text: Il1 | O0 — Small text should remain readable.

Red text and thin coloured lines may soften with 4:2:0 chroma.

Blue text: Il1 | O0 — Compare against the physical monitor.

Motion and pacing

The box moves at 600 CSS pixels/s; frame count follows browser requestAnimationFrame. Watch for jumps or freezes. Actual stream FPS comes from SecondScrn diagnostics.
